Pengaturan Lembaga

Pengaturan Koneksi WebApp Google Apps Script

Masukkan URL Web Application Google Apps Script yang telah Anda Deploy sebagai Web App (Anyone) agar semua data tersimpan di Google Spreadsheet Anda.

Cara Mendapatkan Link Web App:

  1. Buka Script Editor spreadsheet Anda di Extensions > Apps Script.
  2. Klik Deploy > New deployment.
  3. Pilih type Web app, set Execute as: Me, dan Who has access: Anyone.
  4. Klik Deploy dan salin URL Web App yang dihasilkan.
